# Nightreign PvP releases

Player builds only: `release.json`, `NightreignPvP.zip` and `NightreignPvP-Launcher.exe`, published by CI. Get the launcher from the latest release.

Download page: https://aspherya.github.io/nightreign-pvp-releases/ (GitHub Pages, served from `docs/`; this repository has no workflows, so a push here never builds or publishes a release).
