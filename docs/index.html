Nightreign PvP

A Battle Royale mod for ELDEN RING NIGHTREIGN. Land on Limveld as rivals, fight each other and the map, and be the last one standing.

Launcher · Windows · all releases

How to play

  1. Download and run the launcher. It finds your game, installs the mod and keeps both itself and the mod up to date.
  2. Install Seamless Co-op if you do not have it. The launcher opens its Nexus page and installs the zip you download.
  3. Press Play. At the Roundtable, pick the Battle Royale card (the last expedition in the list), set the number of players to Solo and press Commence.
  4. That is the last click. When a match is found, everyone is brought together and the expedition starts on its own.

You need

  • ELDEN RING NIGHTREIGN on Steam (Windows)
  • Seamless Co-op for Nightreign (the launcher helps you install it)
  • The same mod version as the players you meet. The launcher updates you automatically.

Before you run it

Windows may warn you. The launcher is not code-signed, so your browser or SmartScreen may say the file is uncommon. Keep the file, then on the blue "Windows protected your PC" box choose More info > Run anyway.

Your normal game stays normal. The mod runs only through the launcher, without anti-cheat and away from the official servers. Steam's own Play button still starts the regular game. Mod sessions use Seamless Co-op's save, separate from your vanilla save.
